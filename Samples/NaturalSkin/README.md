# Natural Skin Tones

32 additional skin choices, from light to deep, with warm, cool, neutral, and olive variations.

Install **CosmeticsAPI 0.2.0 or newer** on client and server. Merge this pack's **Client** and **Server** folders into the respective game folders, then restart both. Every viewing player needs the same palette version.

Find the swatches in the native **Skin Color** category. This pack uses ATT's existing skin rendering and requires no model bundle.

To edit a palette, import the Creator SDK and choose **Cosmetics API → Create Skin Tone Palettes**. Select `Assets/CosmeticsAPI/Samples/Natural Skin Palette.asset`, edit **Tones**, and export both folders from the Inspector. Keep released SKUs stable. Use a new Pack ID and new per-tone SKUs for a separate palette.
